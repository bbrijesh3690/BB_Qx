Quorum export

Reads this extension's IndexedDB and downloads NDJSON files. Nothing is sent anywhere.

Raw frames

Every recorded WebSocket frame (redacted before storage), one JSON record per line, for schema mapping with npm run analyze-frames -- <file>.

Dataset (bbqx-dataset)

A DatasetMeta line, then tick, feed-candle and payout events ordered by time, for the replay harness. Ticks cover only the ledger's 2-hour window; for a full-length dataset, convert the raw frames with npm run analyze-frames -- <raw.ndjson> --dataset <out.ndjson>.
